Sources & tools

Community sources establish the background; the scripts and records below let readers check specific calculations. A new calculation or explicit certificate is not a claim of first discovery.

The data

eyes.json holds the nine messages as raw eye directions and as symbols. They were decoded from the constants in the game's executable that place the eyes, and agree on all 1,036 symbols with the community transcription by RotBC and ToboterXP; allthemalware reached the same result independently from screenshots. The Noita wiki page has the in-game locations and pictures of the walls.

Scripts

Download eyes.json and the five scripts into one folder. They use only the Python 3 standard library. one_shuffle.py and commute.py import isomorph.py; all four checks import eyes.py. For example, run uv run python one_shuffle.py. Passing a script checks its stated calculation, not whether its plaintext assumptions are true.

eyes.pyloads the messages; run it to rebuild every symbol from the eye rows
isomorph.pychecks an isomorph and prints its copy map, marking which arrows need only R
one_shuffle.pythe three-isomorph argument that K ≥ 2 (isomorphs)
commute.pytwo copy maps that do not commute (isomorphs)
periodic_bound.pythe counting bound for repeating keys (ruled out)

Calculation records

  • Copy-link ledger: aligned cells, repeat support, connected sets and single-shuffle certificates.
  • No-doubles experiment: 400 random keys, then 200 conditioned and 200 designed keys. The setup is described on the model page; it used local game text, which is not redistributed.
  • Block-permutation counts: the exhaustive block-size 2–8 check, not arbitrary transposition.
  • Earlier fill calibration: 200 fills per configuration, using pairwise checks. This is distinct from the later 120-fill closure diagnostic described on the model page.

Community work

The eye messages have been worked on for years, mostly on the Noita Discord. What this site uses:

  • Lymm's eye-messages repository and wiki: the group autokey family, the classification of what isomorphs allow, and pages on shared openings and no doubles.
  • FrobtheBuilder's Eye Cipher Field Notes: the deck model with a few shuffles shared between kinds of letter.
  • allthemalware's noiteyes: an independent reading of the messages from the pixels, and independent exclusions of additive ciphers.
  • lamia-zamia's Noita_eyes: an attack workbench and an archive of earlier community write-ups.
  • tomster12's eye-inspector: a viewer for the messages and their isomorphs.
  • Dr Cats, on the Noita Discord: the chain in cell 0 (messages).

Background
