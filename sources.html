Sources & tools

The data

eyes.json holds the nine messages as raw eye directions and as symbols. They were decoded from the constants in the game's executable that place the eyes, and agree on all 1,036 symbols with the community transcription by RotBC and ToboterXP; allthemalware reached the same result independently from the pixels. The Noita wiki page has the in-game locations and pictures of the walls.

Scripts

Download eyes.json and the five scripts into one folder. They use only the Python 3 standard library. one_shuffle.py and commute.py import isomorph.py; all four checks import eyes.py. For example, run python one_shuffle.py.

eyes.pyloads the messages; run it to rebuild every symbol from the eye rows
isomorph.pychecks an isomorph and prints its copy map, marking which arrows need only R
one_shuffle.pythe three-isomorph argument that K ≥ 2 (isomorphs)
commute.pytwo copy maps that do not commute (isomorphs)
periodic_bound.pythe counting bound for repeating keys (exclusions)

Calculation records

  • Copy-link ledger: aligned cells, repeat support, connected sets and single-shuffle certificates. The file calls a link an arrow and an isomorph span a window.
  • No-doubles experiment: 400 random keys, then 200 conditioned and 200 designed keys. The setup is described on the model page; it used local game text, which is not redistributed.
  • Block-permutation counts: the exhaustive check of block sizes 2–8.
  • Tuck audit: return times and the alphabet size each message would need.
  • Genre screen: every verse form, spaced and unspaced (plaintext).
  • Constraint sheet: which cells are tied, at each level of assumption (plaintext).
  • Earlier fill calibration: 200 fills per configuration, using pairwise checks. The 120-fill closure test on the model page is a later, separate run.

Search records

Each file gives the seed range, variant count, logging cutoff and best candidates of one run of the key searches. In the names below, pick and Fisher–Yates are the two Lua shuffle loops; D12 layouts give letter i read position i, and table layouts give a character its place in the 83-character table; small seeds are 0 to 999,999 and clock seeds are the seconds of the release window. D12 is the file-name label of the clock-seed search. The Lua-recipe runs:

  • LuaJIT pick, D12 layouts, small seeds
  • LuaJIT Fisher–Yates, D12 layouts, small seeds
  • LuaJIT pick, table layouts, small seeds
  • LuaJIT Fisher–Yates, table layouts, small seeds
  • LuaJIT pick, table layouts, clock seeds
  • LuaJIT pick, D12 layouts, clock seeds
  • LuaJIT Fisher–Yates, table layouts, clock seeds
  • LuaJIT Fisher–Yates, D12 layouts, clock seeds
  • MSVC, table layouts, clock seeds
  • glibc, table layouts, clock seeds

The clock-seed runs with std::random_shuffle: MSVC, MSVC, 1 discarded, MSVC, 2 discarded, MSVC, 3 discarded, MSVC, 4 discarded, MSVC, 5 discarded, MSVC, 6 discarded, MSVC, 7 discarded, MSVC, 8 discarded, glibc, glibc, 1 discarded, glibc, 2 discarded, glibc, 3 discarded, glibc, 4 discarded, glibc, 5 discarded, glibc, 6 discarded, glibc, 7 discarded, glibc, 8 discarded.

Community work

The eye messages have been worked on for years, mostly on the Noita Discord. What this site uses:

  • Lymm's eye-messages repository and wiki: the group autokey family, the classification of what isomorphs allow, and pages on shared openings and no doubles.
  • FrobtheBuilder's Eye Cipher Field Notes: the deck model with a few shuffles shared between kinds of letter.
  • allthemalware's noiteyes: an independent reading of the messages from the pixels, and independent exclusions of additive ciphers.
  • lamia-zamia's Noita_eyes: an attack workbench and an archive of earlier community write-ups.
  • tomster12's eye-inspector: a viewer for the messages and their isomorphs.
  • Dr Cats, on the Noita Discord: the chain in cell 0 (messages).

Background

  • The cipher families on the exclusions page: substitution, Vigenère, autokey, affine, transposition.
  • Card and disk ciphers whose steps depend on the symbols themselves, excluded under R: Solitaire, Chaocipher, RC4.
