A class-shuffle model

The mechanism that fits best so far. It produces shared openings, isomorphs, and messages that agree again after differing. No key for it has been found. Here a letter means any character of the unknown text, including a digit or a space, and the alphabet is the set of them.

Read a position, then shuffle

  1. Start each message with the same deck of 83 cards, numbered 0 to 82.
  2. Give every plaintext letter a different, fixed position in the deck.
  3. Output the card at the letter's position.
  4. Apply a fixed shuffle chosen by the letter's class. Letters in the same class use the same shuffle.

The key is the starting deck, the position of each letter, the class of each letter and one shuffle per class. Each message starts again from the starting deck, so messages that begin with the same text begin with the same symbols.

Nine cards, five letters, two shuffles

A small key of the same kind: nine cards, the letters A, B, N, O and S, and two classes. Shuffle 1 follows A and O; shuffle 2 follows B, N and S. A shuffle line lists, for each position, the position its new card comes from.

position              0 1 2 3 4 5 6 7 8
starting deck         1 2 8 4 0 3 5 6 7
shuffle 1 (A, O)      2 3 5 0 6 8 4 1 7
shuffle 2 (B, N, S)   6 2 8 0 5 3 7 4 1
read positions        A 0  B 1  N 2  O 3  S 4

To encipher BANANA: B reads position 1 of the starting deck, which holds card 2, so the first symbol is 2. B is in the second class, so shuffle 2 is applied, and the deck becomes 5 8 7 1 3 4 6 0 2. A reads position 0, card 5. Carrying on gives 2 5 4 3 5 2. The same word after one extra letter, SBANANA, starts from a deck that has been shuffled once more:

              B  A  N  A  N  A
BANANA        2  5  4  3  5  2
           S  B  A  N  A  N  A
SBANANA    0  8  6  1  4  6  8

The two rows share no symbol in the same place, and both repeat in the same places. That is an isomorph at a shift of 1, made by one text met in two deck states. Changing one letter for another of the same class shows the second effect:

           B  A  N  A  N  A
BANANA     2  5  4  3  5  2
           B  O  N  A  N  A
BONANA     2  1  4  3  5  2

A and O read different positions, so the second symbol differs. They are in one class, so the deck afterwards is the same and the rest agrees again.

This is a shared-shuffle version of extended group autokey. See Lymm's formalization and FrobtheBuilder's field notes. The key changes with the plaintext, as in an autokey cipher; here the changes are permutations. The working variant has no extra movement of the card just read. "Class shuffle" is this site's name for it.

What is assumed

The plaintext is unknown, so every statement that two stretches hold the same text is an assumption. An isomorph is a pair of stretches with the same pattern of repeated symbols; its two rows are called copies. Two levels of plaintext correspondence are used on these pages:

  • R: at repeat-supported positions of a selected isomorph, corresponding cells in the two passages hold the same plaintext letter. It is a claim across copies, not just within each row.
  • W: corresponding cells throughout the selected span hold the same plaintext, including positions whose symbols occur only once there.

A position is repeat-supported when its symbol occurs more than once in the row. Matching repeats in two rows are unlikely unless the text matches there; a symbol that occurs once fits any text. W implies R. Both are hypotheses about the listed pairs, and W fails for at least one of them: an isomorph can span a short field where the text differs (example). The model also assumes one starting deck for all messages, fixed read positions, and the same letter-to-shuffle rule throughout. Cell 0 is left outside the cipher.

In notation

Dt          the deck before letter t, a bijection from positions to cards
r(a)        the position letter a reads; different letters, different positions
κ(a)        the class of letter a, one of 1 … K
P1 … PK     the shuffles, fixed permutations of 83 positions

ct = Dt[ r(at) ]                  read
Dt+1[i] = Dt[ Pκ(at)(i) ]          shuffle

K is the number of classes, and so the number of shuffles. The key is (D0, r, κ, P1 … PK). With one shuffle, put Q = D0 P1 D0−1: this is the shuffle expressed on symbols rather than positions. Equal letters at a shift of d then give a symbol map Qd, independent of the start of the passage. The three-copy certificate contradicts K = 1 under R.

Yellow marks the cells where the two messages differ. E1 and W1 differ at cells 25–28, match at 29–32, differ at 33–36, then match again. In this model, replacing a letter with another of the same class changes its output but leaves the next deck unchanged. Equal output does not prove equal decks: two decks can agree at the positions read next, and two different shuffles can cancel.

A double is a property of a letter pair

A double is a symbol followed at once by the same symbol. The eyes have none. The card read for a letter moves when the deck is shuffled, and the next letter reads it again only if the shuffle carried it to that letter's position:

a followed by b produces equal symbols ⇔ Pκ(a)(r(b)) = r(a)

The current deck cancels out of this condition. For a fixed key, every occurrence of the same letter pair has the same outcome. Counted as 1,018 independent draws from 83 symbols, zero doubles would have probability (82/83)1018, about 1 in 230,000. The number of independent trials is the number of different letter pairs in the text, which is far smaller.

A simulation of 400 random keys and English game-text samples at the nine body lengths used 27 plaintext symbols and three randomly assigned classes. It produced a mean of 11.4 doubles, but zero doubles in 4.8% of trials. The figure depends on the text model. Recorded output.

A key built so that no text can ever produce a double is a stronger condition than these messages need. Such a key limits the alphabet to 82 letters; the absence of doubles here does not.

What remains open

The number of classes: at least two, and two to four is the working range. Whether the shuffles are unrelated or small changes to one base. Under W, the E4/E5 break needs a change that moves at least seven symbols (five if the cell at the break is left out).

Whether each letter also swaps two cards that no letter reads (a lift), besides its class shuffle. In a preregistered comparison on the E4/E5 passage, lifts fit better unless the two texts differ often there: at more than about a fifth to a quarter of the cells if the differences are digits, or over a third if they are letters. Without the text that is undecided. The checks below are for the model without lifts. The alphabet, the letter classes, and why the deck has 83 cards are unknown.

Rejecting a guess is easier than verifying one

A crib is a guessed stretch of plaintext, and a fill is a guess for the whole text of all nine messages. The closure check tracks the possible positions of each card through the guessed text: equal read letters must use the same position, and each shuffle must be a one-to-one map. A contradiction rejects that guess under the specified model. No contradiction does not guarantee that a complete 83-card key exists.

The fills obey the constraint sheet, which lists the cells that must hold equal letters, and draw words from English game text, common English and common Finnish; half use number fields. The broader fill-calibration results use the earlier pairwise checks and show substantial variation between text sources.

A solution is the alphabet, starting deck, read positions, class map and shuffles that encrypt the proposed text to all nine messages. A solver that times out has shown nothing either way. How much text a check needs.
